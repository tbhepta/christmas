# Christmas Developer Judge 🎄🎅

A festive TypeScript-based web game that determines whether you're a naughty or nice developer!

## About

This interactive game presents you with 10 developer-themed statements/commands. Swipe left (NOPE) for bad practices or right (NICE) for good practices. At the end, Santa judges whether you belong on the nice list or the naughty list!

## Features

- 🎮 Built with Phaser.js game engine
- ❄️ Christmassy theme with falling snow animation
- 🃏 10 developer practice cards to judge
- ⬅️➡️ Arrow button controls (or keyboard arrows)
- 🎯 Scoring system to determine your developer status
- 🎁 Find out if you deserve a Christmas bonus!

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

```bash
npm install
```

### Running the Game

Development mode:
```bash
npm run dev
```

Then open your browser to `http://localhost:3000`

### Building for Production

```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## How to Play

1. Read the developer statement on each card
2. Click the left arrow (←NOPE) if it's a bad practice
3. Click the right arrow (NICE→) if it's a good practice
4. After 10 cards, see if you're naughty or nice!
5. Play again to test your knowledge!

## Technologies Used

- TypeScript
- Phaser 3 (JavaScript game engine)
- Vite (build tool)
- HTML5 Canvas
